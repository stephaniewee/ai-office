An office of AI agents that runs student life admin

Eight Claude agents each own one job: job hunting, exam quizzes, project deadlines, part-time shift hours and pay, weekly planning, event scouting, portfolio reviews and work availability. They run on schedules in the cloud, share one database, and report back to this 3D office.

  • Human in the loop: I set job statuses, quiz topics, “going” on events and leave notes. Agents pick those up next shift.

  • Agents that collaborate: the planner reads deadlines, shifts, quiz weak spots and events from the others.
